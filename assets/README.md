# Recursos visuais

Adicione nesta pasta os arquivos de imagem, vídeo, logotipo ou outros recursos da sua página.

Exemplos:
- `assets/logo.svg`
- `assets/produto.webp`
- `assets/demo.mp4`

Depois atualize as referências no HTML. Prefira formatos leves e não adicione credenciais ou arquivos privados.
