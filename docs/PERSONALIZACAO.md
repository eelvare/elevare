# Checklist de personalização

- [ ] Definir o nome do produto e a marca.
- [ ] Substituir a headline e a descrição do topo.
- [ ] Adicionar imagens ou vídeo originais.
- [ ] Descrever benefícios reais, público-alvo e modo de uso.
- [ ] Informar conteúdo, preço, entrega e condições reais.
- [ ] Ajustar as perguntas frequentes.
- [ ] Configurar o link HTTPS do checkout em `script.js`.
- [ ] Incluir dados de contato e links para políticas e termos aplicáveis.
- [ ] Testar botões e navegação em celular e desktop.
- [ ] Verificar acessibilidade, desempenho e textos antes da publicação.

**Observação:** este é um template genérico; nenhuma venda, depoimento, desconto, garantia ou prazo é afirmado sem dados fornecidos pelo responsável.
